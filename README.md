# credit-card-app-frontend

### Frontend (Client App)
- **Framework:** React + TypeScript (Vite).
- **Estilos:** Tailwind CSS (Diseño Responsivo y Moderno).
- **Gestión de Formularios:** React Hook Form (Validaciones dinámicas).
- **Iconografía:** Lucide React.
- **Notificaciones:** React Hot Toast.
- **UI/UX:** Animaciones con Tailwind-animate, Scroll interno y máscaras de moneda en tiempo real.

### Pasos para el Frontend
1. Navegar a la carpeta credit-cards-app.
2. Ejecutar `npm install`.
3. Ejecutar `npm run dev`.
